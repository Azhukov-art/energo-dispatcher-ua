# ENERGO DISPATCHER UA

Навчально-ігровий симулятор диспетчера енергосистеми України.

## Функції
- Карта України з областями та переходом до районів (GeoJSON з відкритого набору).
- Умовні ігрові джерела генерації: АЕС, ТЕС, ГЕС, СЕС, ВЕС.
- Рівні підстанцій 750/330/110 кВ як ігрові вузли.
- Автоматичний, ручний і змішаний режими; швидкість 1×/2×/5×/10×.
- Випадкові аварії, ремонтні бригади та таймер ремонту.
- Графік генерації, споживання та частоти.
- Збереження у localStorage браузера.

## Джерела та застереження
Адміністративні межі: `darmat1/ukraine-geo-data` (OpenStreetMap-derived, ODbL). Базова карта: © OpenStreetMap.
Усі електростанції, вузли, лінії, аварії, навантаження та потужності в грі — **умовні**. Це не реальна схема електромережі, не оперативні дані й не система керування інфраструктурою.
